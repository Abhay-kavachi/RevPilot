# Data Generation (World Model)

- **Scale**: 222,433 recovery events
- **Causal Drivers**: Behavioral reliability, temporal penalty (recent failures), exact amounts.
- **Oracle Regret**: The World Model evaluates ALL potential outcomes (Y_wait, Y_email, Y_link) secretly, allowing us to calculate regret vs the optimal decision.
- **Leakage**: Strictly none. Action timestamps drop appropriately.
